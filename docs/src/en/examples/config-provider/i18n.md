# GenuiConfigProvider - Internationalization

`GenuiConfigProvider` supports i18n via the `locale` prop and custom messages via the `i18n` prop.

There are two independent layers:

| Layer | Configuration | Covers |
|-------|---------------|--------|
| GenUI copy | `locale` + `i18n` | Built-in Chat / renderer strings |
| UI library copy | `locale` + `materials` (the package provides `runtimeFactory`) | Pagination, empty states, date pickers, etc. |

Official Vue materials (OpenTiny Vue and Element Plus) ship with `runtimeFactory`. When you pass `materials`, ConfigProvider calls the runtime's `apply()` method (`locale` is `undefined` when omitted). For packages that return a `root`, the same stable `root` carries both the UI library's theme and locale provider, such as Element Plus `ElConfigProvider`; you do **not** need to configure the UI library locale at the application root, and separate theme and locale providers cannot overwrite each other.

> Note that OpenTiny Vue is different: its runtime switches the locale through the global `tinyUse` API outside the root, and the locale package stores that value in module-level global state. Multiple ConfigProviders with different locales therefore share the same global locale, and the last applied one wins. This limitation only affects OpenTiny Vue; Element Plus keeps its locale inside each root's provider, so providers do not interfere with each other. When `locale` is omitted, the OpenTiny Vue runtime does not call `tinyUse`, so the application's current locale is left unchanged.

> Custom `i18n` messages are a Vue ConfigProvider feature. Angular and React currently switch the materials locale through `locale` and do not provide `i18n` message overrides.


## Dynamic Language Switching

Switch language with a reactive variable:

```vue
<template>
  <div>
    <select v-model="locale">
      <option value="zh_CN">简体中文</option>
      <option value="en_US">English</option>
    </select>
    <GenuiConfigProvider :materials="materials" :locale="locale" :i18n="customI18n">
      <GenuiChat :url="url" />
    </GenuiConfigProvider>
  </div>
</template>

<script setup lang="ts">
import { materials } from '@opentiny/genui-sdk-materials-vue-opentiny-vue/materials';
import { ref } from 'vue';
import { GenuiConfigProvider, GenuiChat } from '@opentiny/genui-sdk-vue';

const locale = ref('zh_CN');
const customI18n = {
  // ... custom messages
};
</script>
```

## Custom Messages

Use `i18n` to override or extend default strings. Keys are language codes; values are message objects for that locale.

```vue
<template>
  <GenuiConfigProvider :materials="materials" :locale="locale" :i18n="customI18n">
    <GenuiChat :url="url" />
  </GenuiConfigProvider>
</template>

<script setup lang="ts">
import { materials } from '@opentiny/genui-sdk-materials-vue-opentiny-vue/materials';
import { ref } from 'vue';
import { GenuiConfigProvider, GenuiChat } from '@opentiny/genui-sdk-vue';
import type { I18nMessages } from '@opentiny/genui-sdk-vue';

const locale = ref('zh_CN');

const customI18n: I18nMessages = {
  zh_CN: {
    placeholder: {
      input: '请输入您的问题（自定义）',
    },
    footer: {
      aiGenerated: '内容由AI生成，仅供参考（已自定义）',
    },
  },
  en_US: {
    placeholder: {
      input: 'Please enter your question (customized)',
    },
    footer: {
      aiGenerated: 'Content generated by AI, for reference only (customized)',
    },
  },
};
</script>
```

## Full Message Catalog

To customize more strings, inspect the full message catalog:

```typescript
import { useI18n } from '@opentiny/genui-sdk-vue';

const i18n = useI18n();

console.log(i18n.messages)
```

## UI Library Copy

Pass official materials with `locale` (canonical ids such as `zh_CN` only). Each package maps that id to its own language pack. OpenTiny Vue also ships `es_LA` / `pt_BR`, and TinyNG also ships `es_US` / `fr_FR` / `pt_BR`. An undeclared id falls back to the first item in that list. When `locale` is omitted, the OpenTiny Vue runtime leaves the global locale untouched and the other materials fall back to their default language pack.

To support more languages, add canonical-id → UI-library pack entries in the materials map. Do not change ConfigProvider.

```vue
<template>
  <GenuiConfigProvider :materials="materials" :locale="locale">
    <GenuiChat :url="url" />
  </GenuiConfigProvider>
</template>
```

For custom materials, see [Custom Materials - Materials Runtime](../custom-materials#materials-runtime-theme-and-i18n).
